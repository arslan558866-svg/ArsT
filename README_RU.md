# СОЗДАЙ СЕБЯ — комплект для облачной сборки iOS

Нативный SwiftUI-каркас персонального тренировочного дневника с маскотом-медведем.

## Что подготовлено
- SwiftUI-приложение с вкладками «Сегодня», «Программа», «Прогресс», «Профиль».
- Face ID через LocalAuthentication с системным fallback на код-пароль iPhone.
- План A/B/C: понедельник, среда, пятница.
- Стартовые ориентиры: жим лёжа 65 кг, гравитрон — помощь 40 кг.
- Запись веса и повторений по подходам, самочувствия плеч и поясницы, заметок.
- Локальная история тренировок.
- Еженедельный ввод веса и талии.
- Маскот-медведь, набор AppIcon и анимированная SwiftUI-заглушка для карточек упражнений.
- `project.yml` для генерации Xcode-проекта и `codemagic.yaml` для облачной сборки.

## Важно о готовности
Это подготовленный исходный проект для облачной сборки, а не уже собранный IPA. Из этого чата нельзя подписать приложение вашим Apple Developer аккаунтом или установить его на iPhone.
В проекте:
- Face ID реализован через системный API, но требует проверки на реальном устройстве.
- Упражнения пока показывают анимированную иллюстрацию-заглушку, а не реальные обучающие видео.
- CloudKit/iCloud ещё НЕ подключён; данные пока хранятся локально.
- Перед публикацией нужно заменить Bundle Identifier, настроить подпись, проверить privacy details и пройти тестирование.

## Что нужно сделать без собственного Mac

### 1. Подготовить Apple Developer
Оформить Apple Developer Program и войти в App Store Connect:
https://developer.apple.com/programs/
https://appstoreconnect.apple.com/

### 2. Загрузить проект в GitHub
1. Создать приватный репозиторий на https://github.com/.
2. Распаковать архив и загрузить в репозиторий все файлы, включая `codemagic.yaml`.
3. В `project.yml` заменить `com.yourname.sozdaysebya` на уникальный Bundle ID, например `com.ВАШЕ_ИМЯ.sozdaysebya` (используйте только латинские буквы, цифры и точки).

### 3. Подключить Codemagic
1. Создать аккаунт на https://codemagic.io/.
2. Подключить GitHub и выбрать приватный репозиторий.
3. В Codemagic добавить App Store Connect integration с API key из App Store Connect → Users and Access → Integrations → App Store Connect API.
4. Назвать integration точно `AppStoreConnect`, как указано в `codemagic.yaml`.
5. Включить workflow `ios-testflight` и запустить сборку.
6. Codemagic сгенерирует Xcode-проект, подпишет его профилем и попробует отправить сборку в TestFlight.

### 4. Установить через TestFlight
1. Установить TestFlight из App Store на iPhone.
2. Дождаться обработки сборки в App Store Connect.
3. Добавить себя в список внутренних тестировщиков.
4. Принять приглашение TestFlight и установить «Создай себя».

## Если сборка завершится ошибкой
Скопируйте сюда полный текст ошибки из Codemagic Build → Logs. По нему можно исправить настройки проекта.

## Публикация в App Store
Перед отправкой нужно проверить приложение на реальном устройстве, добавить скриншоты, описание, возрастной рейтинг, сведения о сборе данных и политику конфиденциальности. Не отправляйте приложение на ревью, пока CloudKit, резервное копирование, Face ID и все экраны не протестированы.

## Безопасность тренировок
Показатели боли — только дневник самонаблюдения, не медицинская диагностика. Не выполняйте упражнения через боль; при стойких симптомах нужна очная оценка специалиста.
